# 应用内迁移向导与使用帮助

## Problem
老年使用者不熟悉电脑，不能依赖命令行导出、环境变量或外部文档。需要在程序内完成迁移并随时查看操作步骤。

## Outcome
空库用户可从首次使用入口进入旧资料迁移，按“找到旧资料、核对数量、开始迁移”完成；离线帮助可在任意页面打开且不丢失草稿。

## Scope
- 应用内 MySQL 只读连接；自动探测常见 Tomcat 目录，或选择旧系统文件夹后解析配置/Java DAO/已编译 DAO 常量。凭据仅保存在主进程本次会话，前端只显示已识别状态；高级参数仅在识别失败时由维护者填写。
- 检测本机 MySQL/MariaDB 服务，用户确认后仅启动选中的已识别服务，不安装服务、不修改启动类型、不停止服务、不执行旧目录脚本。权限不足时给出求助说明。远程地址不提供本机启动。
- 支持原有 JSON 作为备用路径，也进入同一预览/确认流程。
- 关闭旧程序录入的确认、只读一致性读取、照片和关联完整性校验；后台线程准备，显示阶段并支持取消。预览药品/处方/照片/总金额/日期范围后，再在空目标库原子导入；迁移前后备份，源数据不改。
- 独立离线帮助入口/F1，覆盖首次使用、开方、金额、查询/修改/作废、照片/打印、备份恢复、迁移和常见故障。大字、大按钮、中文，不要求终端用户安装 Node/MySQL 工具。

## Non-goals
不在本次开发机器上连接诊所真实数据库或启动任何服务；不推断未知密码、不自动提升权限、不删除旧数据、不合并非空库；不修改原 Java 系统。

## Prototype decision
不需要独立原型，沿用现有卡片/弹窗交互。用户已授权本地实现和框架选择。

## Behavior and states
- 连接失败、密码错误、照片缺失、已存在新资料分别显示中文下一步；不自动创建空成功结果。
- 导入确认前只准备独立临时快照，取消/失败不改目标数据库，完成后显示实际数量；重复确认被拒绝。
- 迁移读取设超时和数量/256MB上限；事务引擎一致性快照，非事务旧表使用短期只读锁，失败释放连接。
- 帮助弹窗不会触发离开草稿；迁移执行期间禁用其他编辑动作，进度由后台线程发送；关窗明确提示正在处理。

## Constraints
保留上一轮未提交修改。版本 1.1.0；MySQL 驱动包含在安装包，仅迁移使用。凭据和病历不写诊断日志。
